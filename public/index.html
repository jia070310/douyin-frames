Douyin Frames

本机抖音抽帧工具

v1.1.0

在你自己的电脑上解析抖音链接（或本地视频），用 FFmpeg 导出逐帧图片。 数据不出本机，不作为在线站点使用。

能做什么

  • 粘贴抖音视频或图文（note）链接
  • 上传本地视频按帧或按间隔导出
  • JPG / PNG / WebP，本机预览与保存
  • 手动清理缓存，不自动删你的结果

怎么解析

  1. 优先纯 HTTP 解析
  2. 可选走 yt-dlp
  3. 本机 Edge / Chrome 拦直链（一般不必登录）

使用提示

  • 解析失败时：上传本地视频，或用「高级」里的书签从已打开的作品页带回直链
  • CLI：npm run cli -- "<抖音链接>"
  • 安装版不内置 Node / FFmpeg，首次运行检测不到会下载到本机缓存
  • 便携版也可双击 DouyinFrames.exe 使用
